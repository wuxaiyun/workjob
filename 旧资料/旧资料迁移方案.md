# 旧设备资料一次性迁移方案 · 操作指南

> 目标：把散落在旧表/纸质/Excel 的全部设备资料，整理成**一张标准表格**，用系统「设备批量导入」一次导入完成（含分类专属参数），全程零代码、可校验、可回滚。

---

## 一、方案总览

```
旧资料(任意格式)
    │  AI 整理（按下方提示词 + 标准模板）
    ▼
标准表格.xlsx / .csv（中文表头，一行一台设备）
    │  系统「设备批量导入」→ 先"预演校验"
    ▼
校验通过 → "正式导入"(insert)
    │
设备全部入库（含分类参数 → extra_data）
    │  少量增量/纠错 → 再导时用 upsert
    ▼
大功告成
```

- **范围**：设备主表（含分类专属参数）。维修记录/检定/备件/费用等业务数据不在此次批量导入内，按业务发生逐条录入即可。
- **关键词**：位号唯一、类别枚举对齐、日期 `YYYY-MM-DD`、数值为数字、分类列按行类别填写。

---

## 二、标准表格结构（列清单）

下载方式：系统 →「设备批量导入」→「下载导入模板」，该模板已自动包含**全部列**（基础列 + 分类专属列）。

| 分组 | 列（表头，中文） |
|------|------------------|
| 基础（20列） | 位号、设备名称、设备类别、所属项目、项目编号、所属部门、安装位置、规格型号、生产厂家、供应商、出厂日期、出厂编号、投用日期、资产编号、原值、净值、是否强检、强检有效期、状态、备注 |
| 通用工艺 | 介质、密度、粘度 |
| 阀门 | 口径、量程、填料、泄漏等级、流量特性、压力等级、执行机构型号、连接形式、法兰标准、法兰尺寸、阀体材质、阀芯材质、阀座材质 |
| 仪表 | 量程、准确度、分度值、防护等级、防爆等级、电气接口尺寸 |
| 电机 | 功率、电机型号、防护等级、防爆等级、轴承、减速机 |
| 泵/风机 | 功率、最大流量、正常流量、最小流量、操作压力、操作温度、轴承、减速机、密封件 |
| 锅炉/压力容器 | 压力等级、温度、材质、阀前压力、阀后压力、压差 |

说明：
- 多个类别共用标签的列只出现一次（介质、功率、防护等级、量程等），**任何类别的行都能填同一列**。
- 每行只需填该设备类别的相关列，其余留空；系统自动把填了的值收进该类别的参数分组。
- 列顺序随意、列可缺省；未知列会被忽略。

## 三、分步详细指导

### 第 0 步：准备
1. 确认系统能登录（admin/admin123）。
2. 打开「设备批量导入」页 → 点「下载导入模板」，得到 `设备导入模板.xlsx`。

### 第 1 步：让 AI 整理旧资料（核心）
把旧资料文件 + 模板 + 下方《AI 整理要求》一起交给 AI，产出整理后的标准表格。

### 第 2 步：快速人工抽查
打开 AI 产出的表格，抽查 10-20 行：
- 位号是否全局唯一（可用 Excel：选中位号列 →「数据 → 删除重复值」）。
- 设备类别/状态/是否强检是否与模板值完全一致。
- 日期是否为 `YYYY-MM-DD`，原值/净值是否为数字。
- 中文是否正常（无乱码）。

### 第 3 步：预演校验（安全，不落库）
1. 「设备批量导入」→ 上传整理好的文件。
2. 选择「仅新增（已存在则跳过）」，点**「预演校验」**。
3. 看结果：若"失败 0 行"即可正式导入；若有失败行，页面会列出每行原因，回到 Excel 修正后重新上传。

### 第 4 步：正式导入
- 全新库：模式「仅新增（insert）」→「正式导入」。
- 已有部分数据（补录/增量）：用模板只填要更新的行 → 模式「新增或更新（upsert）」→「正式导入」。upsert 会按位号合并更新，分类参数与旧值合并，不会清空。

### 第 5 步：验收
- 首页：设备总数、强检到期提醒是否正确。
- 打开任意设备详情：分类参数是否正确出现在对应分组。
- 「历史导入记录」可查每次导入的成功/失败行。

## 四、可复制给 AI 的《AI 整理要求》（提示词）

```text
你是一名设备台账资料整理员。请把旧设备资料整理成"标准设备导入表"。

【输出格式】
Excel/CSV。第一行为表头，必须严格使用我提供的列名（模板表头），不要新增、
删除或改名任何列；标题行下面一行一条设备记录。

【硬性规则】
1. 位号：每条设备全局唯一，不能有空格和重复；无法确定位号的设备标注为
   "待定-序号"并放入"未分类"工作表备查。
2. 设备类别：只能取下列值之一（完全一致，不许改写）：
   阀门 / 仪表 / 电机 / 泵/风机 / 锅炉/压力容器 / 其他
   旧资料里"泵""风机"要归入"泵/风机"；"锅炉""压力容器"归入"锅炉/压力容器"。
3. 状态：只能取 在用 / 停用 / 报废。
4. 是否强检：只能取 是 / 否。
5. 日期列（出厂日期/投用日期/强检有效期）：格式一律 YYYY-MM-DD，无法确定留空。
6. 数值列（原值/净值）：必须是数字，无法确定留空（不要写"约""左右"等文字）。
7. 分类参数列：各行只填与该设备类别匹配的列。
   例如：阀门行填 口径/压力等级/阀体材质……；泵/风机行填 功率/最大流量
   /操作压力/轴承……；所有类别都可填 介质/密度/粘度。无关列全部留空。
8. 几条旧记录对应一台设备（如同一设备多条检修信息）时：设备只保留一行，
   其他行信息如有维修价值请汇总到"备注"，不要重复录设备。
9. 拿不准的字段宁可留空，不要猜测填值。
10. 输出完成后，自查：位号无重复、类别/状态/是否强检合法、日期格式正确、
    表格无空表头、无乱码。

【备注】导出的文件需 UTF-8 编码（CSV）或标准 xlsx；如需分卷，每卷不超过
5000 行，且每卷都要带完整表头。
```

### AI 分工建议（资料量大时）
- 第一步用 AI 把非结构化旧资料（扫描件 OCR 结果、PDF、截图、纸质台账照片）识别成文本规范字段。
- 第二步用 AI 把字段填入标准表格并检查规则。
- 由人做最终抽查与预演校验，AI 只负责整理，**导入动作由人工在系统里点**。

## 五、自检清单（打勾项）

- [ ] 表头与模板完全一致（无新增/改名/删除列）
- [ ] 位号无重复、无尾随空格
- [ ] 设备类别 ∈ {阀门,仪表,电机,泵/风机,锅炉/压力容器,其他}
- [ ] 状态 ∈ {在用,停用,报废}；是否强检 ∈ {是,否}
- [ ] 日期全部 YYYY-MM-DD
- [ ] 原值/净值为数字
- [ ] 分类列只填本类别相关列
- [ ] 文件 ≤ 5000 行/卷，UTF-8
- [ ] 「预演校验」失败 0 行后才正式导入

## 六、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 某行报"位号在文件内重复" | 表内位号重复 | 删重或改位号 |
| "设备类别为空/不合法" | 类别值不在枚举内（如"泵"） | 改为"泵/风机" |
| "XX 日期不合法" | 日期带了文字或格式不对 | 改 YYYY-MM-DD |
| "原值 不是数字" | 填了"约8000" | 去文字仅数字 |
| 导入后分类参数没显示 | 设备类别的字段配置里没有该列，或列名拼写不一致 | 「设备参数设置」确认该类字段存在；列名用模板中的 |
| 中文乱码 | CSV 非 UTF-8 | 另存为 UTF-8 CSV，或改用 xlsx |
| 想改已有设备资料 | insert 模式会跳错 | 用 upsert 模式再次导入 |
